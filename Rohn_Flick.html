Pick-ups

Dit script zorgt ervoor dat een speler gezondheid of armor krijgt wanneer hij een object met de juiste tag oppakt (bijv. een medkit of armor pickup). Bij aanraking via een trigger wordt het corresponderende aantal punten toegevoegd aan de speler, en het object verdwijnt daarna uit de scène. Het script werkt samen met een PlayerHealth component waarin de waarden voor health en armor worden opgeslagen.

Throwing

Dit script laat de speler een beperkt aantal projectielen gooien vanuit een aangewezen punt. Bij het indrukken van een ingestelde toets wordt een object gespawned en met kracht vooruit én omhoog geworpen. Het gebruikt Rigidbody physics en een cooldown-systeem om herhaald gooien te beperken. Het script is volledig configureerbaar via de Unity Inspector.

Show Throwing script 

                        public class Throwing : MonoBehaviour
                        {
                             [SerializeField] private Transform player;
                             [SerializeField] private Transform attackPoint;
                             [SerializeField] private GameObject objectToThrow;
                             [SerializeField] private int totalThrows;
                             [SerializeField] private float throwCooldown;
                             [SerializeField] private KeyCode throwKey;
                             [SerializeField] private float throwForce;
                             [SerializeField] private float throwUpwardForce;

                             bool readyToThrow;

                             void Start()
                             {
                                 readyToThrow = true;
                             }

                             void Update()
                             {
                                 if (Input.GetKeyDown(throwKey) && readyToThrow && totalThrows > 0)
                                 {
                                     Throw();
                                 }
                             }

                             private void Throw()
                             {
                                 readyToThrow = false;

                                 GameObject projectiles = Instantiate(objectToThrow, attackPoint.position, player.rotation);

                                 Rigidbody projectileRb = projectiles.GetComponent();

                                 Vector3 forceToAdd = player.transform.forward * throwForce + transform.up * throwUpwardForce;

                                 projectileRb.AddForce(forceToAdd, ForceMode.Impulse);

                                 totalThrows--;

                                 Invoke(nameof(ResetThrow), throwCooldown);
                             }

                             private void ResetThrow()
                             {
                                 readyToThrow = true;
                             }
                        }
